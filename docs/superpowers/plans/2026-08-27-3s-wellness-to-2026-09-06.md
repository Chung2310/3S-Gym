# 3S Wellness đến 06/09/2026 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Phát hành Production Core của 3S Wellness và đưa toàn bộ chức năng Đợt 2, Đợt 3 cùng OCR/AI/RAG vào beta có feature flag trước hết ngày 06/09/2026.

**Architecture:** Giữ React/Vite và Express/Mongoose, hoàn tất TypeScript strict trước khi phát triển mới. Backend tách Route → Controller → Service → Model; frontend tách `PortalPage` thành các feature độc lập; các module beta được chặn ở cả backend và frontend bằng feature flag, còn AI/OCR chỉ tạo bản nháp chờ PT duyệt.

**Tech Stack:** React 19, React Router 7, Vite 8, TypeScript 7 strict, Express 5, Mongoose 9, MongoDB, JWT, Vitest 4, Testing Library, Supertest, Docker, Cloudinary, Gemini-compatible AI provider và MongoDB Atlas Vector Search hoặc vector adapter tương đương.

- Timeline cố định: 28/08/2026–06/09/2026, múi giờ Asia/Saigon.
